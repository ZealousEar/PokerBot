# Over-fold post-mortem — decision frequencies under synthetic pressure

The shipped bot plays a tight, polarized line. The README
[Known limitations](../../README.md#known-limitations) notes that, facing
sustained postflop pressure with marginal holdings, it folds rather than
bluff-catching thin. This post-mortem **quantifies that tendency** as decision
frequencies.

## What this is — and is not

- **Is:** how often `src.bot.decide()` returns fold / call / raise across a
  fixed grid of postflop pressure spots. Generated by a committed script.
- **Is not:** an EV, chip-delta, or bb/100 estimate. Those need the engine match
  harness and a real opponent distribution, neither of which lives in this
  public repo. A high fold frequency on marginal hands describes the strategy's
  *shape*, not a loss. No statistically significant net loss has been
  established here; nothing in this document is a profit-or-loss figure.

## Reproduce

```bash
python tools/overfold_probe.py          # the table below
python tools/overfold_probe.py --json   # per-spot rows
```

Engine-free and deterministic (eval7 equity is seeded from the hand/board
inputs), so the numbers below regenerate exactly.

## The grid

192 spots: 8 hero holdings × 2 board textures (dry A-high, wet QJ9) × 3 streets
(flop/turn/river) × 4 bet sizes faced (1/3, 2/3, pot, 1.5× pot overbet). Hero is
heads-up and out of position, facing a villain bet, deep enough that these are
call/fold spots rather than stack-off math. Strength tiers come from the same
eval7 equity-vs-random the bot uses — a coarse proxy, so most made hands land in
the "strong" bucket and the bluff-catcher zone sits in "medium"/"weak".

## Reading it

- Fold frequency rises monotonically with the bet size faced (16.7% → 29.2%):
  the strategy bet-folds to resistance, as described.
- The folding concentrates in the marginal tier — **67.9%** of medium-strength
  spots fold — while strong hands raise. That is the bluff-catcher gap: hands
  that could profitably continue against some pressuring ranges are folded.
- Strong hands are not over-folded (14.1%); this is a marginal-hand-under-
  pressure shape, not blanket passivity.

## Why it ships this way

Widening the calling range is the natural next revision, but it changes the
strategy *shape* and so reopens the full verification surface (exploitability,
paired benchmarks, mechanism-matched counter-exploit probes). Per the project's
freeze discipline, that belongs in a proper cycle rather than a hot-patch to a
frozen submission. This probe is the mechanism-matched instrument that a future
revision would have to move.
